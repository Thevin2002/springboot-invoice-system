# Springboot Invoice System

Personal project by **Thevin2002**, built on top of an open-source project.

## How to run

Requires **JDK 17**, **Maven** and **MySQL**.

```bash
cd springboot-invoice-system-master
mvn spring-boot:run
```

Set the password in `SpringbootDataJpaApplication.java` (it is `CHANGE_ME` in this repo). Sample data is loaded from `src/main/resources/import.sql`.

Tested: `mvn package` builds successfully on JDK 17.
